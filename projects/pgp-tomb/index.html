PGP Tomb archived go

  • repository

A minimalist, cross-platform command-line secrets manager built on top of PGP.

I mostly made this for fun around 2019, as an excuse to try out Go for the first time. I actually used it as my personal secrets manager for a while, but there are way better options out there now. So, I stopped maintaining it and archived the project.
