Varnish Cache VMOD useful to access contents of environment variables and local or remote files from VCL, usually for configuration purposes, including execution of Lua and JavaScript programs.

This project has been around since 2016 and is running in some pretty demanding production setups. That said, a few features (like JavaScript execution) are kind of experimental—they’re probably not something you’d use in production, and they haven’t been tested all that much.
