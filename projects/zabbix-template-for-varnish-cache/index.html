Zabbix Template for Varnish Cache python zabbix varnish

Zabbix template and companion Python script for monitoring Varnish Enterprise instances.

This template came together back in 2015 to help Varnish Enterprise customers get solid support during incidents. More than a decade later, we’re still maintaining it—though a full rewrite is probably overdue. For now, it does the job pretty well wrangling the endless stream of Varnish Enterprise metrics.
