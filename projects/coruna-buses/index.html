A Coruña Urban Buses archived java android

  • site

An Android app for checking real-time bus schedules and routes across A Coruña’s urban bus network.

Back in 2011, when real-time public transit data first became available in A Coruña, I built this Android app mostly for myself. Pretty wild, considering how much I hate anything UI-related. It was a fun project, but I lost interest once better alternatives showed up.
