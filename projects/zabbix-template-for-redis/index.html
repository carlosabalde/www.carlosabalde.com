Zabbix Template for Redis python zabbix redis

  • repository

Zabbix template and companion Python script for monitoring Redis Server and Redis Sentinel instances.

We originally put this template together back in 2015, alongside the Zabbix Template for Varnish Cache, to help monitor Varnish Enterprise and Redis setups connected using the redis VMOD. Maintenance is still going, but it’s mostly in “life support” mode these days.
