VCLSKi vcl ansible varnish

  • repository

A very opinionated VCL Starter Kit to kickstart Varnish Enterprise projects with a solid skeleton.

It’s basically a minimal starter pack: a well-documented set of VCL files plus a tiny Ansible playbook. Nothing fancy, but it’s been super useful for us and many customers over the years.

The project has been around for many years, but we gave it a name and open-sourced it in 2026.
